# Keras_exhibition_project
This is the project code for the team KERAS on Kangwon Science Exhibition Project. 


This project is about sorting apples and carrots into three groups: The good, The bad, and The ugly

Using rembg, YOLO v8, EfficientNet-V2s model, we suggest fast, efficient, accurate model for the sorting problems.

This is the prototype, so using this in real construction site may occur some problems.
